Analyse IA du téléphone

FACULTATIF

La même analyse des personnages que le studio, appelée directement depuis le téléphone.

Deux chemins. Sans clé : le repérage local lit les indices de dialogue — immédiat, plus approximatif. Avec une clé (ou une IA locale) : le modèle identifie vraiment chaque locuteur — de quelques minutes à plusieurs heures par livre selon le modèle, une nuit entière pour un gros roman. Dans tous les cas, le premier chapitre démarre dès qu'il est prêt et les voix choisies servent tout le livre.

Que se passe-t-il quand elle est activée ?

À l’ouverture d’un livre, les personnages sont identifiés puis les dialogues attribués par ce modèle, avec une relecture critique des passages incertains. La préparation prend plusieurs minutes et consomme des tokens ; chaque lot est sauvegardé et une coupure se reprend sans refaire le travail déjà fait.

Le texte des passages analysés est envoyé au fournisseur choisi. La clé reste chiffrée sur ce téléphone (Android Keystore) : elle n’est jamais réaffichée. Désactivez l’IA à tout moment : le repérage local reprend la main, les attributions déjà obtenues restent acquises.

Votre studio vocal

FACULTATIF

Retrouvez vos voix clonées depuis PK Voice Studio. Les passages générés restent sur le téléphone pour les prochaines écoutes.

Comment connecter mon Mac ?

Démarrez PK Voice Studio, puis la passerelle mobile depuis le dossier du projet :

python3 src/server/mobile_gateway.py

Recopiez l’adresse et le code affichés. Votre téléphone et votre Mac doivent être sur le même réseau. La génération se fait sur le Mac ; l’audio est enregistré sur le téléphone.
